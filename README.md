# Modified Effort-Expenditure for Rewards Task (EEfRT)

Senior capstone research repository at **Abdullah Gül University** examining **effort-based decision-making** and **trial-by-trial outcome carryover**.

## Overview
This study adapts the Effort-Expenditure for Rewards Task (EEfRT) in **PsychoPy** to model how immediate reward feedback and prior trial outcomes dynamically influence subsequent high-effort vs. low-effort choices across varying reward magnitudes and probabilities.

## Tech Stack
- **Task Implementation:** PsychoPy (Python)
- **Behavioral Modeling & Preprocessing:** Python (`pandas`, `numpy`)
- **Statistical Modeling:** SPSS

## Ethics & Data Privacy
Participant behavioral logs are omitted from this public repository in accordance with institutional ethics protocols.
